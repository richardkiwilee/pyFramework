#基本准则
资源、代码、界面分离。
界面UI逻辑单独一个文件，定义锚点。锚点链接资源，如果目标资源没有找到，则使用GDScript原生的控件代替。
代码一个功能点一个文件。
资源专门存放在一个文件夹，方便进行替换。
所有的代码需要详细的注释。我熟练掌握python，没有GDScript经验。


关于编队部分的详细说明
屏幕分为左右两个部分，称之为2个界面容器。
如果界面容器失去了焦点，这个界面容器下的所有控件都应该失效。
左边部分定义为队伍列表界面。
队伍一览界面的左上角是标题“编队管理”，标题独占一行。
然后是三个控件，左箭头、队伍名称、右箭头。使用QE或是点击左右箭头来进行队伍的切换
接下来是队伍的九宫格信息，有九个锚点，用以放置单位。
最下方是2个按钮，分别是新建队伍和解散队伍，解散队伍需要弹窗确认。

右边部分定义为队伍成员界面。
队伍成员界面均分为9个栏位，表示最多可以上场9个单位，每个栏位分成1：4：2，左侧是单位头像，中间部分是单位基本信息，包括等级、经验值、AP/PP。
右侧是单位的装备栏（仅展示）。
当焦点在队伍列表界面时，鼠标点击九宫格区域将焦点进入队伍成员界面。
当点击新建队伍时，新建一个空白的九宫格，然后焦点自动进入它的队伍成员管理界面。

当焦点在队伍成员界面时，按WS或是鼠标悬停在成员直接进行切换，空格或是鼠标左键点击一个成员，弹出操作选项，分别是移动、编辑、设为队长、下场。
虽然单位在九宫格内都有位置，但是队伍成员界面中所有的角色栏位是从上往下紧密排列，第一个空栏位中间显示一个加号，表示添加成员。
操作选项中，如果选择了移动，就将焦点进入九宫格的锚点，WSAD进行循环，如果目标是一个空栏位，则直接移动过去，如果已经存在一个单位，则互换两个单位的位置。
点击下场，就将这个单位移动到待命池。
点击设为队长，直接设为队长，将合法性检查留到退出界面。
点击编辑，进入单位详细界面。
如果从队伍成员界面按ESC将焦点返回队伍列表界面，需要做检查，首先是不是有一个队长，如果没有队长（即没有任何一个单位），允许弹出焦点，但是队伍不再成立，自动删除这个队伍。如果有队长，但是队长的领导力不足，无法容纳全队的规模，则不能弹出焦点，必须进行改正。成功保存队伍时，更新队伍的名字，使用“<队长名>队”。

单位详细界面，位置完全覆盖队伍成员界面，是一个单位的详细信息，包含了完整的角色属性、装备栏和技能编程。点击装备栏的格子或是技能或是条件的时候，弹出“可选界面”。

可选界面的位置完全覆盖队伍列表界面。
装备、技能和条件的卸下操作都在可选界面中，可选界面是一个列表，第一行是卸下。
