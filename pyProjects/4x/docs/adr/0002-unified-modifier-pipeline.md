# 统一修正管道

所有修正源——月相、昼夜、兵种词条、羁绊、信念、技能、装备、地形——经同一条管道收集,以统一结构 (来源类型, 目标, 属性, 数值, 条件) 表达,按目标聚合后按固定顺序计算:先固定加、再百分比乘、最后 clamp 到属性上下界。新增修正源 = 加一枚举项,不新增计算路径。

这是本设计最大的架构难点:8 类修正源都会作用到单位/建筑属性,若各源各自处理会产生重复查询、叠加冲突与难以调试的耦合。考虑过的替代是各来源独立处理(月相/昼夜在回合驱动时查、词条/羁绊在战斗初始化时查、信念在门槛检查时查),实现局部更简单,但多源叠加时无法统一判定计算顺序,百分比与固定值会冲突。统一管道以一次"收集—聚合—计算"换可预测的叠加语义。代价:每次属性取值都要走一次管道收集,开销略高;原型阶段不构成瓶颈,后期可缓存。
