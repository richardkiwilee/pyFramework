# HP 跨战斗累积(不每场回满)

单位生命值跨战斗累积:开打时不回满 HP,单位带伤进入下场,场间仅靠驻扎己方境内每回合恢复(野外 5% / 据点内 10%);AP 与魔力点仍每场战斗开打时回满。设计目标是用 3~4 场连续战斗才能"耗死"一个同等级单位,使升级减伤与连续作战的资源压力成为可感知的机制。

README 未明确 HP 的跨场语义;原型早期按"每场开打回满"实现。本设计废弃每场回满,改为跨战斗累积。考虑过保留每场回满(更接近《圣兽之王》单场结算、玩家不必追踪伤势),其代价是"升级减伤"在单场内难以体现——满血单位一场内要么死、要么近乎无伤,3~4 场耗死的节奏无法成立,等级优势被压平。改为跨场累积后,伤势成为连续作战的累积成本,等级差转化为可观察的战损曲线。代价:玩家需追踪单位伤势、调度轮换,认知负担上升;进攻方若伤害覆盖不了防守方驻扎回血(野外 5% / 据点 10%),该据点对进攻方即不可攻下,需调整编队或提升等级——这是设计上可接受的,进攻方有明确反制路径。

实施约束:训练升级时 HP 按比例保留(cur_hp = floor(new_max × cur_hp / old_max)),不借升级回血;断粮只阻止驻扎回血、不掉血。
