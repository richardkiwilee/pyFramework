# 建造即时 + 据点 size 整数化

普通建筑在据点空槽位建造,支付足额资源即立即建成,无建造回合、无"建造中"状态;占领后空槽即可建。据点的普通建筑槽位数由 `size` 字段以整数直接给出(范围 1~5),不再使用 small/medium/large 字符串枚举。

README 原设定建造需消耗资源 + N 回合,据点规模用 small/medium/large 映射槽位(小 1 / 中 2 / 大 3),且英雄任据点领主时可减少建造回合。本设计废弃建造回合、改即时建成,并将 size 改为整数。考虑过保留建造回合(提供"建造节奏"、可被战况打断的窗口),其代价是需维护 `build_turns_left` / `tick_build` / `is_ready` 一串状态、每回合推进建造、UI 还要呈现"建造中"——原型阶段运营非重点,这层状态属过度设计。即时建成把建造收敛为单次资源校验,UI 三态(已建/空/无此槽位)即可,据点总览表格直接画 5 列。代价:失去"建造耗时"的战略节奏与"打断建造"的战术点;原型不验证该节奏,后期需要时可重新引入。

连带影响:领主(Lord)原职责为"建造 -1 回合",建造即时后该效果在原型中失效。Lord 角色不删除,保留为"待重定义"占位,留待后续赋予新职责。`build_turns_left` / `tick_build` / `is_ready` 等字段与逻辑移除;`SIZE_SLOTS` / `SIZE_CN` 枚举映射移除,`Stronghold.size` 改为 `int`。
