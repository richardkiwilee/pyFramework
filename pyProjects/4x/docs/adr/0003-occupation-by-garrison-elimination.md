# 占领机制:消灭驻军即易主(取代建造占领)

**Status: superseded by [ADR-0012](0012-garrison-abolition-and-landmark-defender-buff.md)** — 驻军系统已整体删除,占领改为"无守直接占 + 标志性建筑守方 buff"。本文记录的"占领难度收敛到单一变量"思路由 ADR-0012 继承,但把"驻军强度"从自动生成的不可编辑驻军改为玩家/AI 自行驻守的部队 + 标志性建筑档位 buff。下文(含"驻军"语义)保留为历史记录。

---

占领一个据点的方式是消灭其据点驻军——驻军被全灭、进攻方进入据点时,据点直接易主,标志建筑转为进攻方版本,无额外回合或建造动作。占领不消耗时间,难度由据点驻军强度(标志性建筑档位)决定。

README 原文设定占领需"指派部队在据点内建造标志性建筑,花费回合数"。本设计废弃该建造占领,改为纯驻军防御。考虑过保留建造制(占领需英雄原地锁定 N 回合、可被打断),其代价是引入"占领进度"持久状态、英雄锁定、防守战中断等多层机制,且与"英雄任领主/队长"的调度体系冲突;驻军制把占领难度收敛到单一变量(驻军强度),机制与中立/敌方据点统一,更易平衡与验证。代价:占领是瞬时的,失去"围城耗时"的战略节奏感;若后期需要该节奏,可通过"驻军未被全灭时每回合回血补兵"已部分提供消耗战窗口,无需回退到建造制。

进一步的简化:据点不再拥有"失能"状态。原设计在"标志建筑被摧毁"与"驻军被全灭"之间存在过渡的失能态(据点无主、归属待重新占领)。本设计将其合并为单一事件——驻军被全灭即所有权立即转移,不存在悬空的失能中间态。这消除了"标志建筑被摧毁但驻军还在"或"驻军被全灭但归属未定"等需要额外规则处理的边界情形。
