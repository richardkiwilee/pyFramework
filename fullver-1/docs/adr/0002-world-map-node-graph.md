# 大地图采用「据点图 + 逻辑坐标投影」，不用六角格 TileMap

战略层地图由**城市节点 + 带权路线边**构成（demo-2 模式），渲染用自定义逻辑坐标系投影手绘（缩放+平移），移动是图上寻路 + 贝塞尔轨迹动画。不用六角格（civ-6 项目的做法）。

**为什么**：①当前玩法锚点是城市与路线（内政/外交/战斗都挂在据点），不是空间地形，图上建模最简单直接；②civ-6 已验证六角格渲染管线成本高昂（绕序/环境光/顶点色 sRGB/色调映射四个深坑），纯手绘投影是 demo-2 验证过的可靠方案；③据点图天然支持 demo-2 的虚线贝塞尔视觉语言，绘制与移动动画共用同一控制点公式（零偏差）。

**代价与回退路径**：没有空间地形（关隘、Zone of Control 等需要格点）。`WorldMapModel` 的接口（节点/边/寻路/坐标）与渲染器分离，未来引入六角格时替换渲染与寻路实现即可，上层不变。

**考虑过的替代方案**：六角格大地图（civ-6 已实现）。否定原因见上，但 civ-6 的几何库与验证经验保留在仓库中备用。
