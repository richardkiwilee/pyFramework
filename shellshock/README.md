# ShellShock Live (单机版 / Godot 4.6)

一个用 Godot 4.6 实现的回合制炮弹对战单机游戏，致敬 ShellShock Live。
全部美术资源用代码即时绘制（圆形/矩形/线/字符串），无外部图片，无音效。

## 运行

用 Godot 4.6 打开本项目（`project.godot`），按 F5 即可运行。
命令行启动：

```bash
"C:/godot/Godot_v4.6.2-stable_win64.exe" --path u:/testing_ai/shellshock
```

## 玩法

- **主菜单**：方向键 ← → 调整玩家数（2-4），E/N/H 切换 AI 难度，M 切换地图（或随机），
  Enter/Space 开始对战，ESC 退出。
- **对战**：
  - `W/A/S/D` 或方向键：调整瞄准角度与发射力度（上/下=力度，左/右=角度）
  - `1`-`8`：快速切换武器（8 个快捷槽）
  - `Tab`：循环全部 50 种武器
  - `Space`/`Enter`：开火
  - `ESC`：返回主菜单
- 玩家 1 是人类，其余为 AI。轮流回合制，每回合 30 秒。
- 每回合风向随机变化，需要预判风力补偿。
- 对战中途会随机空投：`x2 伤害加成`（红色圆形，悬浮空中，吃到后下一次命中伤害翻倍，仅持续 1 回合）、`补给箱`（蓝色，回合开始时落到地面，含回血 / 随机武器）。

## 已实现内容

- **可破坏地形**：基于像素位图的四张预设地图（起伏丘陵 / 台地高原 / 岩石峡谷 / 双子峰），
  爆炸会逐像素挖掘圆形弹坑并实时刷新纹理。
- **50 种武器**（见 `scripts/WeaponDB.gd`），覆盖 9 种弹道行为：
  `basic / spread / cluster / roller / homing / napalm / mine / blackhole / laser / rain`。
- **坦克**：血量、瞄准、炮管绘制、血条、x2 增益闪烁指示，被炸穿地面会坠落。
- **AI**：距离+风力补偿的弹道解算，三档难度控制精度抖动；回合内"调整→开火"两阶段动画。
- **特效区**：火焰（持续掉血 DoT）、黑洞（吸引附近坦克→最终引爆）。
- **地雷**：落地布设，敌方接近触发引爆。
- **补给掉落**：回合开始时有概率空投；x2 为空中红色圆形（持续 1 回合），补给为落到地面的蓝色箱子；大爆炸也有小概率掉落。
- **弹道预测**：瞄准时显示密集虚线弹道预览 + 落点标记。
- **HUD**：当前回合玩家、武器名、力度条、风力计、倒计时、增益、底部武器快捷栏、弹道预测点。
- **胜负判定**：场上仅剩 1 辆坦克时结算（人类胜 / CPU 胜）。

## 代码结构

```
shellshock/
├─ project.godot              # 工程配置 + autoload(Game, WeaponDB)
├─ icon.svg
├─ scenes/
│  ├─ MainMenu.tscn           # 主菜单场景
│  └─ Battle.tscn             # 对战场景
└─ scripts/
   ├─ Game.gd                 # autoload 单例：跨场景状态、随机、字体、坦克配色
   ├─ WeaponDB.gd             # autoload 单例：50 种武器数据
   ├─ MainMenu.gd             # 标题/设置界面
   ├─ Battle.gd               # 对战主控：回合、输入、AI、开火、爆炸结算、补给、胜负
   ├─ Terrain.gd              # 可破坏像素地形 + 4 张地图高度图生成
   ├─ Tank.gd                 # 坦克实体：血量/瞄准/绘制
   ├─ Projectile.gd           # 投射物物理 + 各弹道行为
   ├─ EffectZone.gd           # 火焰 / 黑洞持续特效区
   ├─ Explosion.gd            # 一次性爆炸视觉
   ├─ Pickup.gd               # 补给箱（x2/回血/武器）
   ├─ AimPreview.gd           # 弹道预测虚线 + 瞄准箭头
   └─ HUD.gd                  # 顶部信息条 + 底部武器栏
```

## 说明 / 取舍

- 美术：所有图形均用 `draw_circle/draw_rect/draw_line/draw_string` 即时绘制，
  无任何外部贴图，符合"最简单美术资源"要求。
- 物理：投射物用手写重力+风力积分与像素地形碰撞，未使用 Godot 物理引擎，
  便于和位图破坏地形精确配合。
- 无音效：按要求未加入任何声音。
- 等级/经验：按要求未实现，所有武器开局即用。
