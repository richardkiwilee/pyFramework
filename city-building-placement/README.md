# city-building-placement

Godot 4.6 城市建造管理沙盒原型：六边形地图、四资源、回合制产出、开拓 / 建造 / 升级 / 拆除完整交互链。
核心验收点：**20 个建筑的选择窗口（三栏布局）是否合理**。

## 运行

用 `D:\godot\Godot_v4.6.2-stable_win64.exe` 打开 `project.godot` 后 F5，或：

```
"D:\godot\Godot_v4.6.2-stable_win64_console.exe" --path "d:\pyFramework\city-building-placement"
```

## 玩法规则

- **地图**：flat-top 六边形，半径 3（1 + 6 + 12 + 18 = 37 格），市中心在正中间。距市中心 n 格的格子集合称为 n 环。
- **开局**：拥有 1 环 7 格 + 市中心（特殊建筑，不可拆/不可升级，每回合 +3金1木1食1石）。
- **资源**：金币 / 木头 / 食物 / 石头。点"下一回合"结算全部建筑产出入账；顶部资源栏显示各资源净产出预览。
- **开拓**：点击与领土接壤的空格 → 确认框（显示费用与当前资源）。费用 = 环基准（2环 30金20木 / 3环 80金50木20石）× (1 + 已有地块数 × 5%)。水域/高山可开拓但不可建建筑。无退地。
- **建造**：点击已开拓的空格 → 三栏窗口（左：筛选 tag；中：卡片网格；右：详情 + 建造按钮）。校验：资源、地形要求、相邻要求（磨坊需相邻水域、学院需相邻高山）。
- **升级**：点击已建建筑 → 弹窗。费用 = 基础费 × 2^(目标级−1)；产出每级 +50%（向上取整）；所有加成项每级 +1。等级上限 2/3/4 不等，满级显示"已满级"。
- **拆除**：不返还资源，二次确认；地块保留归属与地形、变回空地。
- **加成**（逐格相邻单独计）：相邻建筑加成、相邻水域加成（食物/经济建筑）、匹配地形加成（如农场@平原+1食）。市中心不参与任何加成。
- **地形**：平原 / 丘陵 / 水域 / 高山，开局全部可见。

## 交互

- 未接壤空格 → 顶部提示条"未与城市接壤，无法开拓"（悬停红色高亮）
- 可开拓空格 → 悬停黄色高亮；已拥有空格 → 悬停白色高亮；领土用绿色环标记
- 相机：固定 45° 俯视角，按住左键拖动平移（位移 >8px 视为拖动）

## 数值调整

全部数值集中在两个数据文件，改完即生效：

- `scripts/data/building_data.gd` —— 20+1 建筑定义（名称/类别/费用/产出/相邻加成/水域加成/匹配加成/地形要求/相邻要求/等级上限）
- `scripts/data/terrain_data.gd` —— 4 种地形 + 37 格手绘布局

地形布局：

```
q:      -3   -2   -1    0    1    2    3
r=-3                      平   平   山   平
r=-2                 平   平   丘   平   平
r=-1            丘   丘   平   平   平   水
r= 0       平   丘   丘   市   平   平   水
r= 1       平   平   平   丘   平   水
r= 2       山   平   平   平   水
r= 3       平   山   山   平
```

（东侧连湖、西南群山弧 + 东北独峰、丘陵散布）

## 项目结构

```
scripts/
├─ hex/hex_geometry.gd        # 六边形几何（轴向坐标、距离、邻居、拾取反算）
├─ data/building_data.gd      # 建筑数据（唯一数值入口）
├─ data/terrain_data.gd       # 地形与布局
├─ game/city_state.gd         # autoload：归属/资源/回合/开拓/建造/升级/拆除/加成结算
├─ world/world.gd             # 37 地块、领土环、悬停高亮、建筑实例
├─ world/hex_tile.gd          # 单地块（地形棱柱 + 高亮盘 + 领土环）
├─ world/terrain_factory.gd   # 程序化网格与共享材质
├─ world/building_factory.gd  # 21 种建筑的几何体组合建模 + 升级装饰件
├─ world/camera_drag.gd       # 固定视角相机（拖动平移 / 点击拾取）
├─ ui/game_ui.gd              # 资源栏 / toast / 开拓确认框 / 三栏建造窗口 / 建筑弹窗
└─ tests/
   ├─ smoke_test.gd           # headless 冒烟测试（逻辑 + 场景 + UI 构建）
   └─ shot_driver.gd          # 窗口截图验证驱动（临时 autoload，见文件头注释）
```
